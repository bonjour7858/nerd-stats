FAQ

Frequently Asked Questions

What is NerdStats?

NerdStats is a public YouTube analytics platform designed to help creators and analysts inspect public engagement metrics, side-by-side video performance, and transparent data insights.

Where does the data come from?

All data is retrieved live directly from the official YouTube Data API v3 provided by Google.

Is the revenue estimate accurate?

No public tool can access exact YouTube earnings. Our revenue range is an estimation based on public views and standard industry RPM ranges ($0.50 - $2.50).

What is NerdScore and how is it calculated?

NerdScore is a custom analytical index (0-100) combining public likes, comments ratio, and audience velocity signals.

Can NerdStats see private YouTube analytics or revenue?

No. NerdStats only accesses publicly available signals. We cannot read private Studio metrics, subscriber retention graphs, or exact RPM.

Can I analyze unlisted or private videos?

You can analyze unlisted videos if you have their URL, but strictly private videos cannot be accessed via the public API.

How is Public Engagement calculated?

Public Engagement is calculated as: (Public Likes + Public Comments) divided by Total Views, expressed as a percentage.

Does NerdStats store my searches?

No. Searches are processed client-side in real-time. We do not store or track your individual search history.

Which languages are supported?

NerdStats supports 7 languages: English, Français, Español, Português, Deutsch, 日本語, and 한국어.

What are the API usage limits?

Requests are governed by Google YouTube API daily quota limits. If a limit is hit, request processing may pause temporarily.
